# Roadmap

## Near term

- Publish signed desktop, Android, and iOS artifacts.
- Expand plugin authoring examples and compatibility guidance.
- Add release smoke tests for the web server and desktop lifecycle.

## Mid term

- Maintain a searchable community plugin catalog.
- Provide a hosted documentation site with versioned API reference.
- Add reproducible builds, provenance, SBOM, and dependency automation.

## Long term

- Build a contributor-led plugin ecosystem.
- Stabilize public extension points and publish compatibility guarantees.

This roadmap is directional. Propose changes through an RFC or GitHub Discussion.
