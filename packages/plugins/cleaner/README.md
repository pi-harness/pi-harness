# @pi-harness/plugin-cleaner

Cleaner — Strict descriptor-safe configuration and parameters, display-safe bounded Pi Harness Git capsule inventory, removal with explicit confirmation and retention controls, symlink and replacement defenses, cancellable serialization, and a fail-closed normalized panel.

## Install

```sh
npm install --save-exact @pi-harness/plugin-cleaner
```

## Enable

Add the entry to the Cordis profile the harness starts from:

```yaml
- id: cleaner
  name: "@pi-harness/plugin-cleaner"
  config: {}
```

The Pi Harness plugin marketplace installs and enables this package for you; the steps above are the manual equivalent.
